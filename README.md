# Saqbol — квиз «Скам или нет?»

Собранный веб-квиз проекта Saqbol: 5 случайных ситуаций (звонки, SMS, переписки), мошенник или нет. Анонимный, на казахском и русском.

Открыть: https://abeako.github.io/saqbol-quiz/
О проекте и данных: https://abeako.github.io/saqbol-quiz/about.html

Здесь только готовый сайт. Исходники и правила — в приватном репозитории проекта (`quiz/`).

## Что добавлено поверх сборки

Эти файлы сделаны вручную, а не сборщиком. При следующей сборке из `quiz/` их нужно сохранить (лучше всего положить в `quiz/public/`):

| Файл | Зачем |
|---|---|
| `about.html` | Страница «Кто мы и как нас проверить» (ru/kk): автор, какие данные собираются, чего Saqbol никогда не попросит |
| `trust.js` | Ставит ссылку на `about.html` под строкой «Озвучка: ElevenLabs» на всех экранах квиза |
| `og.jpg` | Картинка превью ссылки в WhatsApp / Telegram / Instagram (1200×630) |
| `icon.png` | Иконка для «Добавить на главный экран» — маскот вместо заглушки Expo |

В `index.html` добавлены теги Open Graph (`og:image` и др.) и `<script src="./trust.js" defer>`. Их нужно перенести в `quiz/index.html`.

**Правка в сборке, которую надо перенести в исходники:** ссылка «Поделиться» раньше была жёстко задана как `https://abeako.github.io/saqbol-quiz/`. Теперь она берётся из адреса, на котором открыт квиз (`location.origin + location.pathname`), а GitHub-адрес остаётся запасным. Так при переезде на новый домен люди будут делиться уже новым адресом. В исходниках это константа с URL рядом с ключом Supabase.

## Красивый бесплатный адрес

Сайт статический (без сборки на хостинге), поэтому его можно бесплатно подключить к любому из этих хостингов прямо из этого репозитория:

- **Cloudflare Pages** → `saqbol.pages.dev`: Workers & Pages → Create → Pages → Connect to Git → `saqbol-quiz`; Framework preset: None, Build command: пусто, Output directory: `/`.
- **Vercel** → `saqbol.vercel.app`: Add New → Project → Import `saqbol-quiz`; Framework: Other, без build-команды.
- **Netlify** → `saqbol.netlify.app`.

После каждого `push` в `main` хостинг обновится сам. Когда новый адрес заработает, поменяйте «Официальный адрес» в `about.html` (в двух местах: ru и kk).
