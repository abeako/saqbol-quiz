# Saqbol — квиз «Скам или нет?»

Собранный веб-квиз проекта Saqbol: 5 ситуаций (звонки и переписки), одинаковых для всех, — мошенничество или нет. Анонимный, на казахском и русском.

Открыть:
- https://saqbol-quiz.vercel.app/
- https://abeako.github.io/saqbol-quiz/

Страницы по ссылке: `#tips` — «Как не попасться», `#about` — «О нас» (старый адрес `about.html` перебрасывает туда).

Здесь только готовый сайт (папка `dist/` после `npm run build`). Исходники и правила — в приватном репозитории проекта (`quiz/`). Всё, что раньше добавлялось сюда вручную (`about.html`, превью ссылки, иконка, теги Open Graph), теперь собирается из исходников — руками здесь ничего не правим.

Хостинг: Vercel (проект `saqbol`) и GitHub Pages из ветки `main`.
